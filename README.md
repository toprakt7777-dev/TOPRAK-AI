# TOPRAK AI

A private local AI assistant running on Android/Termux.

TOPRAK AI uses:

- Qwen 3.5 4B Instruct
- llama.cpp
- Vulkan / Turnip
- Android shared storage
- A local web interface

No root, Magisk, PC, or cloud API is required.

---

## Requirements

Recommended:

- Android device
- ARM64 / aarch64
- Termux
- Vulkan-capable GPU
- At least 8 GB RAM
- Around 5 GB+ free storage

A device with an Adreno GPU and Turnip Vulkan support is recommended.
